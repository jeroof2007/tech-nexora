TECH NEXORA WEBSITE — STARTER PROJECT

Files:
- index.html: website structure and content
- style.css: design, responsive layout, and animations
- script.js: mobile menu and scroll reveal effects

HOW TO RUN ON YOUR DELL / WINDOWS LAPTOP:
1. Download and extract the ZIP file.
2. Open the extracted tech_nexora_website folder in VS Code.
3. Open index.html.
4. If you have the Live Server extension, right-click index.html and choose "Open with Live Server".
   Otherwise, double-click index.html to open it in your browser.

NOTES:
- This is a front-end starter website, not a deployed live website.
- The contact button opens an email draft. Replace hello@technexora.com with your real business email when you have one.
- The font loads from Google Fonts, so internet access is needed for that font.
- The 3D-inspired artwork is created with CSS, so no separate image asset is required.
